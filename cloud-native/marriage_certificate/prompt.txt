Your task is to build a professional, modular document generation engine using Python and fpdf2 that reproduces the official bilingual (French/English) Cameroonian Marriage Certificate almost identically to the provided template.

The objective is to build a reusable document rendering framework capable of supporting multiple government documents in the future.

The project must follow SOLID principles, clean architecture, and high-quality software engineering practices.
